Sandusky County Probate Court

Website Accessibility Improvements Report — Final

Standard: WCAG 2.1 Level AA  |  Date: May 2025  |  Prepared by: Digital Kingdom Interprises

Project Scope: Audit and remediation of accessibility barriers across the Sandusky County Probate Court website (sanduskycountyprobatecourt.com) to meet ADA compliance requirements under WCAG 2.1 Level AA. All 13 files — including shared infrastructure and all content pages — have been reviewed and corrected. Changes cover semantic HTML structure, ARIA attributes, keyboard navigation support, screen reader compatibility, heading hierarchy, image alt text, link context, form accessibility, table accessibility, and phone/address markup.

Common Fixes Applied Across All Pages

  • Skip link: <a href="#main-content" class="skip-link">Skip to main content</a> added to every page for keyboard navigation
  • Main landmark: <main id="main-content"> added to every page so the skip link target is valid
  • Page titles: Every page given a unique, descriptive title in the format Page Name | Sandusky County Probate Court via dynamic PHP variable
  • Heading hierarchy: Each page verified to have one H1, with subsections using H2 and H3 in proper order — no skipped levels
  • FAQ headings: All FAQ questions changed from <span class="dki-boldhead"> inside <p> to semantic <h3> elements throughout estates.php and guardian.php
  • External links: All links opening in a new tab include an aria-label warning of "(opens in new tab)"
  • PDF links: All PDF links include "PDF" and "(opens in new tab)" in their aria-label
  • Non-descriptive links: All "SEARCH HERE" and "here" links given descriptive aria-label values explaining their destination and purpose
  • Phone links: All phone numbers converted to <a href="tel:..."> with aria-label="Phone: ..."
  • Invalid HTML: <ul> and <table> elements removed from inside <p> tags throughout; <form> element removed from inside <p> tag
  • Malformed tags: </<h3> tag errors corrected in estates.php and adopt.php
  • Decorative icons: All Material Icons used for decoration or layout marked with aria-hidden="true"
  • Table accessibility: Data tables given <caption> elements and <th scope="col"> column headers
  • Address markup: Contact address blocks wrapped in semantic <address> elements
