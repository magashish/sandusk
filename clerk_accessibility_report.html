Overview

This report documents WCAG 2.1 Level AA / ADA Title II accessibility findings for the Sandusky County Clerk of Courts PHP website. Ten PHP template files were audited. All corrections are accessibility-only — no visual design or layout changes were made.

Client Action Items

The following items require a decision or verification by the client before they can be resolved.

FileItemAction Required
All pages Orange <h1> text over parallax photo background Test contrast ratio with a tool like WebAIM Contrast Checker against the actual photo. If ratio fails 4.5:1, switch to white or a darker accessible color.
nav.php dropdown-clyde2 links to FilingFees2013.pdf (2013) while dropdown-clyde links to 25_court_costs.pdf Verify which filing fee document is current and remove or update the outdated link.
nav.php http://codes.ohio.gov/ — uses HTTP Confirm whether https://codes.ohio.gov/ is available and update accordingly.
contact_clerk.php Email clerk@co.sandusky.oh.us — old domain Confirm if mailbox has migrated to @sanduskycountyoh.gov. Update both href and display text if so.
cp_forms.php <h2 class="orange-text">Supreme Court of Ohio Forms</h2> Test orange text on tan background for 4.5:1 contrast. Update color if failing.
cp_forms.php Database output not escaped — XSS risk (security, not WCAG) Developer to confirm htmlspecialchars() additions are compatible with existing data and that no double-encoding occurs.
Required CSS Additions (Stylesheet)

The following rules must be added to the site's main stylesheet. They have no visual effect except where noted.

RulePurposeVisual Effect
.skip-link { position:absolute; top:-50px; left:0; background:#2e5e4e; color:#fff; padding:10px 18px; font-size:14px; font-weight:bold; text-decoration:none; z-index:99999; border-radius:0 0 4px 0; }
.skip-link:focus { top:0; }		 Shows skip-to-content link on keyboard focus (WCAG 2.4.1) Invisible until Tab key — then appears top-left
.sr-only { position:absolute; width:1px; height:1px; padding:0; margin:-1px; overflow:hidden; clip:rect(0,0,0,0); white-space:nowrap; border:0; } Visually hides elements while keeping them in the accessibility tree None — invisible to sighted users
#card-sect h2 { font-size: 1.64rem; line-height: 1.3; margin: 0; } Resets Materialize h2 defaults so card heading size matches original h4 and parallax hero overlap is preserved Cards look identical to original design
h3.card-header { margin: 0; } Resets Materialize h3 margins on card headers in contact_county.php Card header height unchanged
