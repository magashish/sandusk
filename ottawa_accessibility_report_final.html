Ottawa County Clerk of Courts

Website Accessibility Improvements Report — Final

Standard: WCAG 2.1 Level AA  |  Date: May 2025  |  Prepared by: Digital Kingdom Interprises

Project Scope: Audit and remediation of accessibility barriers across the Ottawa County Clerk of Courts website (ottawacountyclerkofcourts.com) to meet ADA compliance requirements under WCAG 2.1 Level AA. All 9 files — including shared header/navigation and footer — have been reviewed and corrected. Changes cover semantic HTML structure, ARIA attributes, keyboard navigation support, screen reader compatibility, heading hierarchy, image alt text, form labeling, link context, table accessibility, and iframe identification.

Common Fixes Applied Across All Pages

  • Skip link: <a href="#main-content" class="skip-link">Skip to main content</a> added to every page for keyboard navigation
  • Main landmark: <main id="main-content"> added to every page so the skip link target is valid
  • Page titles: Every page given a unique, descriptive title in the format Page Name | Ottawa County Clerk of Courts
  • Heading hierarchy: Each page verified to have one H1, with subsections using H2 and H3 in proper order — no skipped levels
  • External links: All links opening in a new tab include an aria-label warning of "(opens in new tab)"
  • PDF links: All PDF links include "PDF" and "(opens in new tab)" in their aria-label
  • Decorative icons: All Material Icons used for decoration marked with aria-hidden="true"
  • Invalid HTML: <ul> elements removed from inside <p> tags throughout
