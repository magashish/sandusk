This report documents the WCAG 2.1 Level AA / ADA Title II accessibility audit performed on the Sandusky County Sanitary Engineers website. The site is built on Materialize CSS, a Material Design framework. A total of 52 accessibility fixes were identified and corrected across 11 PHP templates, spanning navigation, ARIA labeling, heading hierarchy, form accessibility, modal dialogs, carousel media controls, and output encoding.

The most impactful single change is the skip navigation link added to nav.php, combined with id="main-content" added to every page's content area, enabling keyboard and screen-reader users to bypass the navigation bar on every page. The skip link requires a small CSS addition (documented at the end of this report) to remain visually hidden until focused.

Seven pages (duties, stats, contractors, forms, faq, links, pay) share an identical simple template pattern. Each required the same two fixes: a unique descriptive <title> and a <main id="main-content"> landmark. These are documented together as a group for clarity.

4. Skip Link CSS (Required)

The skip link added to nav.php must be visually hidden by default and revealed only on keyboard focus. Add the following to css/style.css:

.skip-link {
  position: absolute;
  top: -40px;
  left: 0;
  z-index: 9999;
  padding: 8px 16px;
  background: #000;
  color: #fff;
  font-weight: bold;
  text-decoration: none;
  transition: top 0.2s;
}

.skip-link:focus {
  top: 0;
}

When a keyboard user presses Tab as their first action on any page, the link slides into view at the top of the screen, allowing them to jump directly past the navigation to the main content area. Sighted mouse users never see it. This satisfies WCAG 2.4.1 – Bypass Blocks.
