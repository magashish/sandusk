This report documents the WCAG 2.1 Level AA / ADA Title II accessibility audit performed on the Sandusky County Court website (sanduskycountycourt.gov). The site is built on Bootstrap 5, a modern CSS framework that provides a solid structural foundation but requires additional ARIA instrumentation for full screen-reader compatibility.

The audit covered all 14 PHP templates including three shared includes (head.php, nav.php, foot.php) that propagate fixes to every page. A total of 116 accessibility fixes were identified and corrected, spanning heading hierarchy, keyboard navigation, ARIA labeling, form accessibility, motion sensitivity, and secure output encoding.

The most impactful single change is the skip navigation link added to nav.php, which — combined with id="main-content" added to every page's <main> element — enables keyboard and screen-reader users to bypass the navigation bar on every page of the site. The skip link is visually hidden until focused, requiring a small CSS addition documented at the end of this report.

4. Skip Link CSS (Required)

The skip link added to nav.php is present in the HTML but must be visually hidden by default and revealed on keyboard focus. Add the following CSS to your site stylesheet or inside a <style> block in foot.php: 

.skip-link {
  position: absolute;
  top: -40px;
  left: 0;
  z-index: 9999;
  padding: 8px 16px;
  background: #000;
  color: #fff;
  font-weight: bold;
  text-decoration: none;
  transition: top 0.2s;
}

.skip-link:focus {
  top: 0;
}

This keeps the link invisible to sighted mouse users. When a keyboard user presses Tab as their first action on any page, the link slides into view at the top of the screen, allowing them to jump directly to the main content area. This satisfies WCAG 2.4.1 – Bypass Blocks.
