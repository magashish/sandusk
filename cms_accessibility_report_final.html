Scope: This audit covers 30 pages of the Sandusky County CMS website. All corrections were implemented as accessibility-only fixes — no visual design or layout changes were made. Each page was reviewed against WCAG 2.1 Level AA success criteria and ADA Title II requirements. Corrected HTML was provided for each page for manual implementation in the CMS.

Items Requiring Client Action

The following items were flagged during the audit and require client verification or additional assets:


  • Email mismatches (×6 pages): Community Corrections, Emergency Management, Emergency Medical Services, Facility Management, Human Resources, Sanitary Engineer — email href uses old domain (co.sandusky.oh.us) while display text shows new domain (sanduskycountyoh.gov). Client to verify correct address for each.
  • Video captions (Job & Family Services): SC Foster Care video requires a .vtt captions file to comply with WCAG 1.2.2. Client to provide captions file.
  • Facebook link (Law Library): Facebook page mentioned with no URL. Client to provide Facebook page URL for linking.
  • Veterans Crisis Line image: Badge image was not linked. Connected to https://www.veteranscrisisline.net/ — client to verify this is the correct destination.
